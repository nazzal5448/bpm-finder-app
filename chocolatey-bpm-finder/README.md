# Chocolatey Package for BPM Finder App

Official Chocolatey Windows Package for **[BPM Finder App](https://bpmfinderapp.com)**.

## Installation on Windows

```powershell
choco install bpm-finder-app
```

## Pack & Push

```powershell
choco pack
choco push bpm-finder-app.1.0.0.nupkg --api-key YOUR_CHOCO_API_KEY
```
