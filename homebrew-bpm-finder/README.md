# Homebrew Formula for BPM Finder App

Official Homebrew tap and formula for **[BPM Finder App](https://bpmfinderapp.com)** on macOS and Linux.

## Installation

```bash
# Add Homebrew Tap
brew tap nazzal5448/bpm-finder-app

# Install BPM Finder App CLI
brew install bpm-finder-app
```

## Usage

```bash
bpm-finder-app 120
```

Powered by [BPM Finder App](https://bpmfinderapp.com).
