# Arch Linux AUR Package for BPM Finder App

Official Arch Linux User Repository (AUR) PKGBUILD for **[BPM Finder App](https://bpmfinderapp.com)**.

## Installation on Arch / Manjaro / EndeavourOS

```bash
# Using yay
yay -S bpm-finder-app

# Using paru
paru -S bpm-finder-app
```

## Manual PKGBUILD Build

```bash
makepkg -si
```
