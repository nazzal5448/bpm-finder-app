# Maven Central Package for BPM Finder App

Official Maven Central Java/Android package for **[BPM Finder App](https://bpmfinderapp.com)** (Domain Authority 91).

## Maven Dependency

Add to your `pom.xml`:

```xml
<dependency>
    <groupId>com.bpmfinderapp</groupId>
    <artifactId>bpm-finder-app</artifactId>
    <version>1.0.0</version>
</dependency>
```

## Gradle Dependency

Add to your `build.gradle`:

```groovy
implementation 'com.bpmfinderapp:bpm-finder-app:1.0.0'
```
