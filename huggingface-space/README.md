# BPM Finder App - Hugging Face Space

Official Hugging Face Space for **[BPM Finder App](https://bpmfinderapp.com)**.

## Features
- **Audio Tempo Detection**: Calculate song tempo (BPM) and average beat intervals.
- **Interactive Tap Metronome**: Tap along to count BPM in real time.
- **Delay & Reverb Calculator**: Compute millisecond values for 1/4, 1/8, 1/8d, 1/16, and triplet delay divisions.
- **Zero Upload Privacy**: Powered 100% locally inside your browser with zero data collection.

Visit the official web application at **[https://bpmfinderapp.com](https://bpmfinderapp.com)**.
